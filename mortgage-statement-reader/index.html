Read my mortgage statement

Fill in your current loan from a PDF statement in seconds. The file is read inside this tab and never leaves your device.

How it works

The page uses PDF.js, the same open-source reader built into Firefox, running locally in your browser to pull out text. It looks for common statement labels such as "Unpaid principal balance", "Interest rate", "Principal", "Interest", "Escrow" and "Maturity date", then shows what it found so you can check it before anything is used.

Privacy

There is no server: the file isn't uploaded, stored or logged. Only the numbers you confirm are saved, in your own browser, so the other tools can use them.

Questions

Why weren't all values found?

Every servicer formats statements differently. Anything not found is left for you to fill in, and you can paste statement text instead.

Does it work with photos?

Photos and scans contain no text layer, so the page shows the image beside the form for you to type values in.
